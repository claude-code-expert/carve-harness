WHY핵심 — "취향"이 아니라 "게이트"

이 데모가 말하는 것

오른쪽 결과는 운 좋게 잘 나온 게 아닙니다. 시각 작업 전에 anti-ai-slop 스킬이 발동되고, 파일을 쓰는 즉시 PostToolUse 훅이 check-slop.mjs를 돌려 ERROR 수를 보고하며, ERROR 0이 될 때까지 재작성하도록 강제됩니다. 눈대중이 아니라 종료코드가 완료 기준입니다.

사실 경계는 다른 층에서 막힙니다. CLAUDE.md의 "미검증 완료 선언 금지", AGENTS의 "빈 입력을 채운 척 금지", 그리고 근거 문서 자체의 §14 표현 경계를 정본으로 읽고 따르는 규칙입니다. 왼쪽은 문서를 읽고도 마케팅 관성으로 덮어썼고, 오른쪽은 문서가 비워 둔 곳을 비워 두었습니다.
