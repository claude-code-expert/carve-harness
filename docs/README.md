# `docs/` — 문서·예시 (리포 참조용, 대부분 미설치)

세션에 자동 로드되지 않는 참고 자료. 필요할 때 읽는다.

| 경로 | 무엇 |
|---|---|
| `rules/code-convention/` | 스택별 코딩 표준 상세본 10종(`.claude/rules/` 슬림본의 근거). 언어팩과 함께 설치 |
| `md/` | 오케스트레이션·verify-loop 가이드 · `eval/`(평가 체계 P0~P3 리포트) · `language-packs/`(LP0~LP5 설계) |
| `evaluator/<lang>-example/` | LLM-judge 예시 5종(코드형+모델형 채점 배선). 언어팩과 함께 설치 |
| `html/` | 데모·가이드 HTML(`carve-guide` 스킬 산출물) |

> `docs/rules/`·일부 `docs/md/*`·`docs/evaluator/*`만 설치 manifest에 포함. 나머지는 소스 리포 전용.
