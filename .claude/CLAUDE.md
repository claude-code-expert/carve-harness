## Claude Code 고유 지침

- skip-permission 모드에서 사소한 분기(파일 이름, 포맷 등)는 기본값으로 진행하고 1줄 고지한다.
- 모델 라우팅: 계획·분석·대형 검증은 상위 모델(높은 추론 강도), 기계적 작성·반복 작업은 하위 모델에 위임한다.
- 시각 산출물 도구 게이트(정본 §7의 구체화): 작업 전 설치된 UI/UX 스킬(anti-ai-slop·theme-factory)을
  먼저 발동하라. 테마·색·폰트 방향은 theme-factory로 탐색하되, anti-ai-slop 금지 목록과 충돌하면
  금지 목록이 이긴다. 생성·수정 후 자동 검사기(check-slop 등)가 있으면 통과할 때까지 재작성하라.

## 지침이 효과를 내고 있다는 신호

diff에 불필요한 변경이 없다. 과도한 복잡성으로 인한 재작성이 없다. 같은 지적을 두 번 받지 않는다.
산출물을 실재 확인 없이 완료 보고하지 않는다. 시각 결과물에 그라데이션·글로우·장식 효과가 없다.
지정 범위 밖 파일이 변경되지 않는다. 덮어쓰기로 기존 작업이 사라지지 않는다. 확인 질문이 구현 전에 나온다.
