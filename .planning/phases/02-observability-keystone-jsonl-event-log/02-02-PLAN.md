## Phase Goal

**As a** harness operator, **I want to** have format-hook failures written to the JSONL log instead of vanishing into `/dev/null`, **so that** a missing or broken formatter becomes visible (C8) instead of silently skipping.

<sub>Derived from ROADMAP Phase 2 Goal. MVP structure: one end-to-end slice — a format-hook fire produces a real, verifiable outcome record.</sub>

<objective>
Resolve C8: PostToolUse format failures currently vanish into `2>/dev/null`. Restructure `posttool-format.sh` so every fire records exactly one outcome (`format-ok` / `format-fail` / `format-skip`) in the JSONL — while keeping the formatter's own noisy stdout silenced and keeping the hook non-blocking (exit 0).

Purpose: OBS-02 makes formatter failures observable without adding transcript noise. The subtle correctness points (from RESEARCH): PostToolUse `exit 2` is NON-blocking (Pitfall 5) so the hook MUST stay `exit 0` and record the failure only in the log; and "surface only the failure" refers to the formatter's stdout — the JSONL still gets one line per fire (Pitfall 7, SC1). This plan reuses the Plan 01 helper — it adds no new logging machinery.

Output: a restructured `posttool-format.sh` (missing / error / ok / skip detection + one log call per arm, formatter stdout still `2>/dev/null`, exit 0) and an executable test proving a `format-fail:missing` record appears and the hook stays exit 0.
</objective>

  bash log-event.sh PostToolUse <formatter> <decision> <file> [reason]
    decision = format-ok | format-fail | format-skip
    reason   = missing | error   (only with format-fail)
  Best-effort subprocess; always exits 0; cannot change the caller's exit code.

Current posttool-format.sh (the file being restructured):
  - f=$(jq -r '.tool_input.file_path // empty' 2>/dev/null)   ← currently reads stdin via jq directly
  - case "$f" in
      *.java)                 [ -x ./gradlew ] && ./gradlew spotlessApply -PspotlessFiles="$f" -q 2>/dev/null ;;
      *.ts|*.tsx|*.js|*.jsx)  command -v pnpm && pnpm exec prettier --write "$f" 2>/dev/null ;;
    esac
  - exit 0   ← MUST stay 0 (PostToolUse exit 2 is non-blocking; Pitfall 5)

Decision mapping (RESEARCH §Pattern 5, re-confirmed):
  recognized ext + formatter ABSENT     → format-fail, reason=missing   (satisfies SC2)
  recognized ext + formatter ran, EXIT≠0 → format-fail, reason=error
  recognized ext + formatter ran, EXIT 0 → format-ok
  UNrecognized ext (catch-all `*)`)      → format-skip                  (SC1: one line per fire)
</interfaces>
