<objective>
Make the Stop gate un-loopable and jq-safe without disturbing the existing stack verification. Add a `stop_hook_active` short-circuit (surface once, exit 0) so a forced continuation cannot loop forever, and a jq-absent best-effort branch (warn + exit 0) so completion is not paralyzed on jq-less machines.

Purpose: `stop-verify.sh` currently reads NOTHING from stdin, so it cannot see `stop_hook_active` and could loop on repeated Stop passes. GATE-01 requires reading stdin and yielding on the second pass. D-02 keeps verification best-effort (non-blocking) when jq is missing — unlike the write guard (Plan 01), hard-failing verification here would make completion impossible on a jq-less box.

Scope note: GATE-02 (the explicit Stop `timeout`) is a `settings.json` edit and is handled in Plan 04, NOT here. This plan touches only the script. Do not add timeout logic to the script. Per **D-07** (keep verification lightweight — compile+test only; change-scoped incrementalization is deferred to Phase 5 GATE-03), this plan preserves the existing pipefail + stack-detection compile/test block exactly as-is and adds ONLY the `stop_hook_active` loop guard — no build-scope changes.

Output: A hardened `stop-verify.sh` with the loop guard layered on top of the untouched pipefail + stack-detection logic, plus an executable test.
</objective>
