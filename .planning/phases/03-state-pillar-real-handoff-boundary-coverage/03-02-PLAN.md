## Phase Goal

**As a** harness operator who ends a session normally (not just via compaction), **I want** a handoff saved on `SessionEnd` too, **so that** ordinary exits leave the same recoverable state a `PreCompact` would — closing the boundary gap in the state pillar.

<sub>Derived from ROADMAP Phase 3 Goal (SC2). MVP structure: one thin end-to-end slice — a normal session-end event produces a real, written handoff and one audit log line, reusing Plan 01's collection. This plan adds the boundary + the SAFETY-gated registration.</sub>

<objective>
Add the `SessionEnd` entry point (STATE-02) without duplicating collection logic. Two moves:

1. **Event-label plumbing (autonomous)** — the save arm currently logs a hardcoded `PreCompact`. Make it log `${2:-PreCompact}` so `session-handoff.sh save` behaves exactly as before (PreCompact) and `session-handoff.sh save SessionEnd` reuses the identical collection/write path but logs the `SessionEnd` event (D-08 single implementation + D-10 correct label). This is the entire reason SessionEnd can share the save arm instead of forking a new one.

2. **Registration (SAFETY-gated, manual)** — register `SessionEnd` in `settings.json` as `bash ${CLAUDE_PROJECT_DIR}/.claude/hooks/session-handoff.sh save SessionEnd` (D-09, CFG-02 prefix). Per `.claude/rules/safety.md`, settings.json changes require explicit user approval — this task is `type=manual` and the plan is `autonomous: false`, so execution pauses for approval before writing settings.json.

Constraints: both PreCompact and SessionEnd overwrite the same `specs/HANDOFF.md` — last-wins is intentional (D-10/D-13). The existing 5 hook events, `$schema`, and `permissions` block in settings.json stay byte-for-byte; the file must remain jq-parseable. Depends on Plan 01 (the save arm must already do real collection before SessionEnd points at it).

Output: a one-line label change in `session-handoff.sh`, a SessionEnd block in `settings.json`, a SessionEnd-label assert in `session-handoff.test.sh`, and a SessionEnd-registered assert in `settings.test.sh`.
</objective>
