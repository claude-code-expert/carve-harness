## Phase Goal

**As a** harness operator resuming after a compaction or session break, **I want** the saved handoff to contain my real unfinished TODOs, open next steps, and recent decisions — not a `[내용없음]` placeholder — **so that** the state pillar carries genuine continuity instead of theater.

<sub>Derived from ROADMAP Phase 3 Goal (SC1, SC3). MVP structure: one thin end-to-end slice — running the save path against real project state produces a handoff a human could actually resume from. This plan makes the `save` collection real; Plan 02 adds the SessionEnd boundary.</sub>

<objective>
Make `session-handoff.sh save` collect and write real content, resolving C7 (STATE-01) and reflecting logged decisions (STATE-03). Replace the single hardcoded `- TODO: [자동 수집 — 내용없음]` line with a structured handoff assembled from four best-effort sources:

1. **미완료 (TODOs)** — the `### Pending Todos` section of `.planning/STATE.md` (D-01).
2. **다음 단계 (next steps)** — open plans: any `.planning/phases/*/*-PLAN.md` with no sibling `*-SUMMARY.md` (D-02); plus the `### Blockers/Concerns` items from STATE.md.
3. **진행 상황** — current branch (already present) plus a git uncommitted **count only** (D-03 — never paths).
4. **주의점/결정** — the most-recent 5 entries from `specs/DECISIONS.md` (D-05), omitted gracefully if the file is absent (D-06).

Purpose: the handoff is the state pillar's payload. Today it is empty by construction. The load-bearing constraints are D-14 (best-effort — a missing STATE.md or DECISIONS.md must never crash the hook; keep the final `exit 0`), D-13 (overwrite semantics — snapshot, not append), and D-03 (count only, no paths — PII posture inherited from Phase 2). The `start` arm, the existing `PreCompact handoff save` log call, and the final `exit 0` are preserved byte-for-byte.

Output: an edited `save` arm in `session-handoff.sh`, and an extended `session-handoff.test.sh` whose Phase-2 sentinel-preserved assertion is inverted and which now proves a seeded TODO and a seeded decision both appear in the written handoff.
</objective>
